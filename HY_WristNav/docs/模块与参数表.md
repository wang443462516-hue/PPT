# V0.1 模块与参数表

## 包名

| 端 | 值 |
|---|---|
| Android | `com.hy.wristnav` |
| Vela | `com.hy.wristnav` |
| 原版（仅分析） | `io.github.fpm0312.watchnav` |

## 消息

| 字段 | 类型 | 说明 |
|---|---|---|
| `v` | number | 协议版本，当前为 `1` |
| `t` | string | `nav_snapshot`、`hello`、`request_snapshot`、`stop` |
| `seq` | number | 手机端单调递增序号；手表重复序号丢弃 |
| `ts` | number | Unix 毫秒时间戳 |
| `source` | string | `amap_notification` 或 `manual_demo` |
| `live` | boolean | 真导航为 `true`，演示为 `false` |
| `state` | string | `navigating`、`arrive`、`stop`、`recalculating`、`no_data`、`disconnected` |
| `maneuver` | string/null | `left`、`right`、`straight`、`slight_left`、`slight_right`、`uturn`、`arrive` |
| `metersToTurn` | number/null | 距下一动作，米 |
| `road` | string/null | 脱敏后道路名 |
| `remainingMeters` | number/null | 剩余路线距离，米；V0.1 通知没有时为 null |
| `etaMinutes` | number/null | 剩余分钟；只在可可靠解析时填写 |
| `speedKph` | number/null | V0.1 为 null |
| `headingDegrees` | number/null | V0.1 为 null |
| `parserRule` | string/null | 诊断规则名，不参与渲染逻辑 |

## freshness

手表在收到 `nav_snapshot` 后以 `ts` 计算新鲜度。默认超过 30 秒显示“数据过期”；连接关闭显示“手机断开”；没有有效数据显示“等待导航”。

## 失败码

| 码 | 含义 |
|---|---|
| `NOT_AMAP` | 非高德通知 |
| `NO_NAV_FIELDS` | 没有可识别的转向或距离 |
| `FOCUS_UNREADABLE` | `miui.focus.param` 存在但不是可读取 JSON |
| `TRANSPORT_UNAVAILABLE` | 尚未接入 Xiaomi Android interconnect SDK |
