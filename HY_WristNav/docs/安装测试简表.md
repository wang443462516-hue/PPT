# V0.1 诊断候选版安装

1. 从同一次云端构建下载 APK 和 RPK，两端包名均为 com.hy.wristnav。
2. 手机安装 APK；用 AstroBox 把 RPK 安装到 Watch S4。保留原版程序即可，两者包名不同。
3. 小米运动健康正常连接手表；打开手机 HY_WristNav 并授权通知使用权。
4. 打开手表 HY_WristNav，再点手机“重连手表”“发送 DEMO”。
5. 手表显示 DEMO、左转、90 m 后，查看手机“手表渲染确认 seq”是否更新。
6. 点击 STOP 应清除导航。再启动真实高德导航，手表应显示 LIVE；收不到通知、解析失败、发送失败分别看手机诊断项。
7. 停止收到有效数据 30 秒后应清除箭头并提示过期；断开连接应明确显示失联。
8. 手表自然息屏，30 秒后原生抬腕，记录回到导航页还是表盘。该行为尚未真机验证。

默认震动关闭，可在手表页面底部切换；不请求常亮。
通知正文默认遮蔽，只显示长度、字段名等诊断摘要。日志中不输出完整导航 payload。

## 当前证据

已通过：云端 Android 编译和解析器测试、Vela 编译、手表状态回归测试。
配套签名：以下载包内 certificate-sha256.txt 和云端 verify-delivery 检查结果为准。
未通过真机验收：真实高德自动同步、抬腕返回导航、功耗、实际 UI 布局和震动体验。
尚未实现：手动 JSON 编辑面板、完整日志导出，以及凭真实通知样本验证过的焦点通知适配。
