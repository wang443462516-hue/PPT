# 安装说明（V0.1）

## 当前状态

本轮已生成源码，但当前工作站没有 Java/Gradle/Android SDK/AIoT-IDE，因此没有伪造 APK 或 RPK 构建成功结果。

## Android

1. 安装 Android Studio、Android SDK Platform 35、Build Tools 35.x、JDK 17。
2. 在 `android/` 执行 `gradlew.bat :app:assembleDebug`。
3. 安装 `android/app/build/outputs/apk/debug/app-debug.apk`。
4. 在系统“通知使用权”中启用 HY_WristNav。
5. 打开应用，先使用“发送 DEMO”验证 UI；真实高德导航必须显示 `LIVE`，不得以 DEMO 代替。

## Vela

1. 用 Xiaomi AIoT-IDE/官方 Vela 工具打开 `watch/`。
2. 在本机生成并保管签名；不要提交私钥。
3. `watch/src/manifest.json` 的 package 必须与 Android `applicationId` 完全一致。
4. 用同一签名体系构建 RPK，并通过 AstroBox 侧载到 Watch S4。
5. 真机安装前确认不会覆盖原版 `io.github.fpm0312.watchnav`。

## 互联前提

Vela 官方文档要求快应用和 Android 三方应用的包名及签名一致。当前源码包名统一为 `com.hy.wristnav`，但本轮还没有 Xiaomi Android interconnect SDK，因此需要在 Android 端将 `LoggingWatchBridge` 替换为真实 SDK 适配器后再做互联验收。
