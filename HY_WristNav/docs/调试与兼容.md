# 调试与兼容

## 已确认

- 原 APK 静态包含高德包名过滤、`NotificationListenerService`、`android.title`、`android.text`、`miui.focus.param` 和 `NavBridge` 字符串。
- 原 RPK 静态包含 `system.interconnect`、`system.vibrator`、DEMO 数组和 `stop` 清除逻辑。
- 新包名为 `com.hy.wristnav`，不会与原包名并行安装冲突。

## 未确认

- 当前高德/HyperOS 版本是否把导航通知投递给第三方监听器。
- 通知中 `miui.focus.param` 的真实字段形状。
- Xiaomi Android interconnect SDK 的本地依赖及签名接入流程。
- Watch S4 熄屏后抬腕是回到 RPK、表盘还是其他页面。
- S01–S08 真机测试、功耗、延迟和电量消耗。

## 抬腕实验边界

手表端只调用 `brightness.setKeepScreenOn({ keepScreenOn: false })`，不申请常亮，不使用加速度计检测抬腕，也不声称可强制替换系统表盘。请按 `docs/测试记录.md` 逐项记录现场结果。
